# To-paz is open-source !

#### <mark style="color:blue;">For non-developers:</mark>

It is important to understand what open source means. The entire To-paz code is public. This means any developer can review the code and contribute to its development. It also means that you can inspect the project yourself using your favorite AI. Transparency is not optional.

#### <mark style="color:blue;">For developers:</mark>

To-paz is distributed under the [MIT License](https://tlo.mit.edu/understand-ip/exploring-mit-open-source-license-comprehensive-guide), and contributions of any size are greatly appreciated. I try to keep open issues for contributors of all skill levels, so even if you are completely new to zero-knowledge technology, your help is still valuable.

Do not hesitate to open issues, ask questions, or contribute for the first time.

A proper `CONTRIBUTING.md` is still a priority and already part of the [roadmap.md](roadmap.md "mention").
