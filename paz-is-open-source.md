# Paz is open-source !

If you are a non-developer you should know that open-source means that the project code is always open and public - not like to-paz donations that can be partially private. For you it means that developers all other the world can inspect the code, as well as YOU can inspect it with your favorite LLM - and ensure you enjoy how it looks like before using the Dapp.

If you are a developer:
